# Portfolio Site

Personal portfolio for Mark Mathews — clean, light, Scandinavian-leaning presentation aimed at Nordic employers.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS (utilities) + custom design tokens

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Content lives in `src/config.ts`.
